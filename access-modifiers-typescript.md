Access Modifiers in typescript - OOP

OOP organizes code using classes and objects. In typeScript, access modifiers control how class properties and method can be accessed. They help developers implement encapsulation, private, protected key term. 

there are lots of access modifiers. 

1. Public : Members can access from any class

2. Private : Members from the same class can access

3. Protected : Can get access from its subclass

4. readonly : members can read it. No one can change or write it.
